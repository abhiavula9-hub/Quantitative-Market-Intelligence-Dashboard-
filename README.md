# Quantitative Market Intelligence Dashboard

## Overview

An interactive quantitative financial analytics dashboard built using Python, Streamlit, Plotly, and Yahoo Finance APIs.

The platform analyzes market trends, volatility, momentum, sentiment, and correlation between financial assets while providing educational insights and interpretability-focused visualizations.

## Features

* Real-time stock market data
* Interactive Plotly charts
* Moving average analysis (MA20 / MA50)
* Volatility modeling
* Correlation analysis between assets
* Sentiment scoring system
* Risk classification
* Trend and momentum interpretation
* Educational tooltips and explanations
* Natural-language market summaries

## Tech Stack

* Python
* Streamlit
* Plotly
* Pandas
* NumPy
* yFinance
